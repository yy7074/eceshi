# 微信开发者工具「下载基础库版本 失败」解决

## 一、项目里已做的配置

在 `manifest.json` 的 `mp-weixin` 中已设置 **`libVersion: "2.25.0"`**，构建后会用较稳定的基础库版本，减少下载失败。

重新编译后再用微信开发者工具打开：

```bash
cd frontend
npm run dev:mp-weixin
```

然后用微信开发者工具打开 **`dist/dev/mp-weixin`** 目录。

---

## 二、工具内快速处理（推荐先做）

### 1. 切换调试基础库（最有效）

1. 在微信开发者工具顶部菜单点 **「详情」**
2. 打开 **「本地设置」** 标签
3. 找到 **「调试基础库」**
4. 下拉选一个**已缓存的版本**（如 **2.25.0**、**2.30.0**），不要选「最新」或未下载的版本

这样就不依赖当前失败的那次「下载基础库」，一般能直接运行。

### 2. 关闭代理

1. 菜单 **「设置」→「代理设置」**
2. 选 **「不使用任何代理」**
3. 确定后重启开发者工具

### 3. 清除缓存

1. 菜单 **「工具」→「清除缓存」**
2. 选 **「清除全部缓存」** 或至少清除「文件缓存」
3. 重启开发者工具后重新打开项目

### 4. 确认登录

- 用**正式微信开发者账号**登录，不要用游客
- 若提示登录异常，先退出再重新扫码登录

---

## 三、若仍失败（网络/环境）

- **网络**：基础库从 `res.servicewechat.com` 下载，公司网络或 DNS 可能拦截，可换手机热点或其它网络试一次。
- **hosts**：若改过 hosts 或用了科学上网，可暂时恢复默认，关掉代理再试。
- **重装工具**：以上都无效时，可卸载微信开发者工具后从 [微信公众平台-开发-开发工具](https://mp.weixin.qq.com/debug/wxadoc/dev/devtools/download.html) 重新安装。

---

## 四、本仓库中的版本说明

- 当前在 `manifest.json` 里写的是 **`libVersion: "2.25.0"`**，兼容性较好。
- 若你本地工具里**没有 2.25.0**，可在「调试基础库」里选一个你本地已有的、不低于 2.19 的版本先跑起来，再根据需要改 `manifest.json` 里的 `libVersion` 为同一版本号（字符串，如 `"2.30.0"`）。

按「一」重新编译 + 「二」里切换调试基础库，一般即可正常运行小程序。
