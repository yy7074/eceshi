## 使用方法

### 1. 确保数据库已配置

确保 `.env` 文件中的数据库配置正确：

```bash
DATABASE_URL=mysql+pymysql://root:password@localhost:3306/eceshi?charset=utf8mb4
```

### 2. 运行测试数据插入脚本

```bash

python backend/insert_admin_test_data.py
```

## 常见问题

### 1. 数据库连接失败
**问题**: 提示数据库连接失败
**解决**: 
- 检查 `.env` 文件中的 `DATABASE_URL` 配置
- 确保MySQL服务已启动
- 确保数据库已创建

### 2. 数据已存在
**问题**: 提示某些数据已存在
**解决**: 
- 这是正常的，脚本会自动跳过已存在的数据
- 如果需要重新插入，请先清空相关表

### 3. 权限错误
**问题**: 访问后台管理页面时提示权限不足
**解决**: 
- 使用管理员账号登录
- 用户名: `admin`
- 密码: `123456`

### 4. 订单分配接口返回422错误
**问题**: 访问订单分配相关接口时返回422错误
**解决**: 
- 确保已登录管理员账号
- 检查请求参数是否正确
- 确保数据库中有待分配的订单数据

### 5. 分类接口返回404错误
**问题**: 访问分类接口时返回404错误
**解决**: 
- 确保API路由正确注册
- 检查URL路径是否正确: `/api/v1/admin/categories`

## 注意事项

1. **数据一致性**: 脚本会尽量保持数据的一致性，但如果数据库中已有数据，可能会产生一些不一致
2. **密码安全**: 测试用户的密码都是 `password`，生产环境请修改
3. **时间数据**: 所有时间都是基于当前时间生成的，可能需要调整
4. **图片URL**: 使用了占位图片，实际使用时需要替换为真实图片
5. **随机性**: 部分数据是随机生成的，每次运行结果可能不同
