## 归档说明

- `archive/root/`: 根目录历史总结、阶段报告、测试记录、修复说明
- `archive/frontend/`: 前端阶段性页面说明、UI 改造总结、检查清单
- `archive/backend/`: 后端历史说明、修复记录、旧问题文档
- `archive/assets/`: 历史 docx/pdf 和从 docx 提取出的中间文件

归档文档默认视为历史资料，不再作为当前实现状态的依据。需要判断当前问题时，优先看 [当前代码状态](./CURRENT_STATUS.md) 和实际代码。
