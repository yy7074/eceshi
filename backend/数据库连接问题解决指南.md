# 数据库连接问题解决指南

## 问题描述

运行测试数据脚本时出现 MySQL 认证错误：

```
pymysql.err.OperationalError: (1045, "Access denied for user 'root'@'localhost' (using password: YES)")
```

## 原因分析

这是 MySQL 数据库连接认证失败，通常由以下原因引起：
1. MySQL root 密码不正确
2. MySQL 服务未启动
3. 数据库 `eceshi` 不存在
4. MySQL 用户权限配置问题

## 解决方案

### 方案一：检查并更新数据库配置

#### 1. 检查当前配置

查看 `backend/app/core/config.py` 中的数据库配置：

```python
DATABASE_URL: str = "mysql+pymysql://root:password@localhost:3306/eceshi?charset=utf8mb4"
```

#### 2. 创建或更新 `.env` 文件

在 `backend/` 目录下创建 `.env` 文件，覆盖默认配置：

```bash
cd backend
cat > .env << 'EOF'
# 数据库配置
DATABASE_URL=mysql+pymysql://root:你的实际密码@localhost:3306/eceshi?charset=utf8mb4

# Redis配置（可选）
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_DB=0
REDIS_PASSWORD=

# JWT配置
JWT_SECRET_KEY=your-jwt-secret-key
JWT_ALGORITHM=HS256
JWT_ACCESS_TOKEN_EXPIRE_MINUTES=1440
EOF
```

**注意**：将 `你的实际密码` 替换为你的 MySQL root 密码。

### 方案二：重置 MySQL root 密码

#### 1. 停止 MySQL 服务

```bash
# macOS
sudo mysql.server stop

# 或使用 Homebrew
brew services stop mysql
```

#### 2. 以安全模式启动 MySQL

```bash
sudo mysqld_safe --skip-grant-tables &
```

#### 3. 连接到 MySQL 并重置密码

```bash
mysql -u root
```

在 MySQL 命令行中执行：

```sql
FLUSH PRIVILEGES;
ALTER USER 'root'@'localhost' IDENTIFIED BY '你的新密码';
FLUSH PRIVILEGES;
EXIT;
```

#### 4. 重启 MySQL 服务

```bash
# 停止安全模式
sudo killall mysqld

# 正常启动
sudo mysql.server start

# 或使用 Homebrew
brew services start mysql
```

#### 5. 更新配置文件

将 `.env` 文件中的密码更新为新密码。

### 方案三：创建数据库和用户

#### 1. 连接到 MySQL

```bash
mysql -u root -p
```

#### 2. 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS eceshi 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
```

#### 3. 创建专用用户（推荐）

```sql
-- 创建用户
CREATE USER IF NOT EXISTS 'eceshi'@'localhost' IDENTIFIED BY 'eceshi_password';

-- 授予权限
GRANT ALL PRIVILEGES ON eceshi.* TO 'eceshi'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;
```

#### 4. 更新 `.env` 配置

```bash
DATABASE_URL=mysql+pymysql://eceshi:eceshi_password@localhost:3306/eceshi?charset=utf8mb4
```

### 方案四：验证 MySQL 连接

#### 1. 测试 MySQL 连接

```bash
# 使用命令行测试
mysql -u root -p

# 或使用 pymysql 测试
python3 -c "
import pymysql
try:
    conn = pymysql.connect(
        host='localhost',
        user='root',
        password='你的密码',
        database='eceshi'
    )
    print('✅ MySQL 连接成功！')
    conn.close()
except Exception as e:
    print(f'❌ MySQL 连接失败：{e}')
"
```

#### 2. 测试 SQLAlchemy 连接

```bash
cd backend
python3 -c "
from app.core.config import settings
from sqlalchemy import create_engine

try:
    engine = create_engine(settings.DATABASE_URL)
    conn = engine.connect()
    print(f'✅ SQLAlchemy 连接成功！')
    print(f'数据库URL: {settings.DATABASE_URL}')
    conn.close()
except Exception as e:
    print(f'❌ SQLAlchemy 连接失败：{e}')
"
```

### 方案五：使用 SQLite（仅用于开发测试）

如果 MySQL 配置困难，可以临时使用 SQLite：

#### 1. 修改 `backend/.env`

```bash
DATABASE_URL=sqlite:///./eceshi.db
```

#### 2. 重新运行测试数据脚本

```bash
python backend/insert_admin_test_data.py
```

## 常见问题

### Q1: 如何查看 MySQL 当前密码？

```bash
# 查看 MySQL 进程
ps aux | grep mysql

# 查看 MySQL 配置文件
cat /etc/my.cnf
cat /usr/local/etc/my.cnf  # macOS Homebrew
```

### Q2: MySQL 服务未启动怎么办？

```bash
# macOS
sudo mysql.server start

# 或使用 Homebrew
brew services start mysql

# 检查状态
sudo mysql.server status
```

### Q3: 如何查看 MySQL 版本？

```bash
mysql --version
```

### Q4: pymysql 不支持 caching_sha2_password 怎么办？

这是 MySQL 8.0+ 的默认认证方式，可以修改为 mysql_native_password：

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的密码';
FLUSH PRIVILEGES;
```
