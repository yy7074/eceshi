# 快速启动测试数据指南

## 问题说明

您遇到的是 MySQL 数据库连接认证错误：

```
(pymysql.err.OperationalError) (1045, "Access denied for user 'root'@'localhost' (using password: YES)")
```

## 快速解决步骤

### 步骤 1：验证 MySQL 连接

首先测试 MySQL 是否能正常连接：

```bash
mysql -u root -p123456
```

如果连接成功，会看到 MySQL 提示符 `mysql>`，输入 `exit` 退出。

如果连接失败，请检查：
- MySQL 服务是否启动：`sudo mysql.server start`
- MySQL 密码是否正确

### 步骤 2：创建数据库

运行数据库设置脚本：

```bash
chmod +x backend/setup_database.sh
bash backend/setup_database.sh
```

或者手动执行：

```bash
mysql -u root -p123456 << EOF
CREATE DATABASE IF NOT EXISTS eceshi 
CHARACTER SET utf8mb4 
COLLATE utf8mb4_unicode_ci;
EOF
```

### 步骤 3：验证数据库已创建

```bash
mysql -u root -p123456 -e "SHOW DATABASES LIKE 'eceshi';"
```

应该看到 `eceshi` 数据库。

### 步骤 4：运行测试数据脚本

```bash
cd backend
python3 insert_admin_test_data.py
```

## 如果仍然失败

### 方案 A：修改 MySQL 认证方式

MySQL 8.0+ 默认使用 `caching_sha2_password`，pymysql 可能不支持。

```bash
mysql -u root -p123456 << EOF
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';
FLUSH PRIVILEGES;
EOF
```

### 方案 B：创建专用用户

```bash
mysql -u root -p123456 << EOF
CREATE USER IF NOT EXISTS 'eceshi'@'localhost' IDENTIFIED WITH mysql_native_password BY 'eceshi123';
GRANT ALL PRIVILEGES ON eceshi.* TO 'eceshi'@'localhost';
FLUSH PRIVILEGES;
EOF
```

然后更新 `backend/.env` 文件：

```bash
DATABASE_URL=mysql+pymysql://eceshi:eceshi123@localhost:3306/eceshi?charset=utf8mb4
```

### 方案 C：使用 SQLite（仅开发测试）

如果 MySQL 配置困难，可以临时使用 SQLite：

1. 修改 `backend/.env`：
   ```bash
   DATABASE_URL=sqlite:///./eceshi.db
   ```

2. 运行测试数据脚本：
   ```bash
   python3 backend/insert_admin_test_data.py
   ```

## 完整执行流程

```bash
# 1. 启动 MySQL

# 2. 创建数据库
mysql -u root -p123456 << EOF
CREATE DATABASE IF NOT EXISTS eceshi 
CHARACTER SET utf8mb4

# 3. 修改认证方式（如果需要）

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '123456';

# 4. 运行测试数据脚本
cd backend
python3 insert_admin_test_data.py
```

## 常见问题

### Q1: 如何查看 MySQL 版本？

```bash
mysql --version
```

### Q2: 如何查看 MySQL 服务状态？

```bash
sudo mysql.server status
```

### Q3: 如何重启 MySQL？

```bash
sudo mysql.server restart
```

### Q4: pymysql 不支持 caching_sha2_password 怎么办？

使用方案 A 修改认证方式为 `mysql_native_password`。

### Q5: 如何查看当前数据库配置？

```bash
cat backend/.env | grep DATABASE_URL
```
